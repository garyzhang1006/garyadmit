# Revise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `garyadmit revise` and a web "Make it a lot better" panel that return a revision plan and draft in the student's voice, labeled verified only when a blind judge prefers the draft over the original in both orders and every gate passes.

**Architecture:** New `garyadmit/revise.py` runs reviser, local gates, fidelity check and a two-order revision judge, retrying once with the failures. Prompts and schemas live in `garyadmit/rubric.py` with the others. The server runs revisions as jobs on the existing job table and writes them back into the saved review.

**Tech Stack:** Python 3.10+ stdlib only (difflib, re, concurrent.futures), `claude -p` via `garyadmit.llm.ask_json`, vanilla JS page, pytest with the schema-driven fake model.

**Spec:** `docs/superpowers/specs/2026-09-27-revise-design.md`

## Global Constraints

- No new Python dependencies; stdlib only.
- No local compute beyond `claude -p` calls; nothing downloads models.
- At most 2 rounds, 4 model calls per round (reviser, fidelity, judge x2).
- At most 4 bracketed questions per draft (`MAX_BRACKETS = 4`); none when `placeholders=False`.
- Every quote shown to the user is verified against the text it claims to come from with `scoring.locate` / `scoring.quote_ok`.
- All essay and model text reaching the page goes through the `html\`\`` auto-escaping template; no raw innerHTML (a security hook blocks it).
- Model prompts fence untrusted text with `rubric.fence()`.
- Copy follows the owner's style rules: no em dashes, none of the banned words, plain sentences.

## Review Focus

1. Bracketed questions that contain a stock phrase ("[what your passion for robots looked like]") must not fail the new-phrase gate: gates lint the draft with brackets removed.
2. A supplement with no word limit (`word_limit=None`) must skip the limit gate without crashing.
3. A saved review from an older version (no `problems`, `strengths`, `calibration`, or `id`) must still produce a context and a revision.
4. A revise request for a review id that does not exist must end the job with a readable error, not a traceback or a hang.
5. A fidelity flag whose quoted text is not in the draft (the checker hallucinated it) is ignored rather than failing an honest draft.

```python
BRACKET = re.compile(r"\[[^\[\]\n]{3,300}\]")

def strip_brackets(text: str) -> str:
    return BRACKET.sub(" ", text)

def _phrases(text: str) -> set[str]:
    rep = lint(text, None)
    return {re.sub(r"\s+", " ", text[s:e].lower()) for h in rep["hits"] if h["rule"] in PHRASE_RULES for s, e in h["spans"]}

def gates(original, revised, meta, placeholders=True):
    if not revised.strip():
        return ["The draft is empty."]
    fails = []
    if " ".join(revised.split()) == " ".join(original.split()):
        fails.append("The draft is identical to the original.")
    limit = meta.get("word_limit")
    wc = word_count(revised)
    if limit and wc > limit:
        fails.append(f"The draft is {wc} words, over the {limit}-word limit. Brackets count toward the limit.")
    new = sorted(_phrases(strip_brackets(revised)) - _phrases(original))
    if new:
        fails.append("The draft adds stock or AI-sounding phrases the original did not have: " + ", ".join(f'"{p}"' for p in new) + ".")
    if _moral_ending(strip_brackets(revised)) and not _moral_ending(original):
        fails.append('The draft now ends by stating the lesson ("I learned...", "I realized..."). End on a moment or image instead.')
    rate = lambda t: (t.count("—") + t.count(" -- ")) / max(1, word_count(t)) * 100
    if rate(revised) > max(rate(original), 1.0):
        fails.append("The draft adds em dashes, which read as AI-polished prose. Use periods and commas.")
    n = len(BRACKET.findall(revised))
    if n and not placeholders:
        fails.append(f"The draft has {n} bracketed notes; this run allows none. Work only with what the essay says.")
    elif n > MAX_BRACKETS:
        fails.append(f"The draft has {n} bracketed questions; keep at most {MAX_BRACKETS}, the ones that matter most.")
    return fails
```

`PHRASE_RULES = {"cliche", "ai_tell", "thesaurus"}`; `_moral_ending(t)` applies `lint.MORAL_ENDING` to the last paragraph. `diff_segments` tokenizes with `re.findall(r"\S+\s*", text.strip())`, compares lowercase stripped tokens with `difflib.SequenceMatcher(autojunk=False)`, emits equal text from the revised tokens, and computes shares from matching blocks. `review_context` follows the spec's list, tolerating missing keys with `.get`.

## Deferred minor findings from the final review

- review ids use check-then-write, so two reviews finishing in the same second can share an id
- pollJob throws a TypeError instead of a readable message when the server has lost the job
- fidelity flags that cannot be located are dropped without a count
- move "rewrite" text is never checked against the draft or the fact check
- a verified result that came from the retry is disclosed only as "Took 2 rounds"
- _name_drafts misses phrasings like "the first draft" or "Essay 2"

- history write-back is non-atomic, and CLI and server write-backs to one review can lose one revision
